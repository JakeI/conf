# texlates = LaTeX Templates

Contains templates for selfcontained latex stuff.
The idea is to copy those using the shortcuts in UltiSnips

- `compdf/compdf.tex` = componde pdf or combine pdf combines a bunch of other pdf into a single document
- `kitter/kitter.tex` = kit letter
- `note/note.tex` = a simple report like template
- `imgs/*` tikz vectorgraphic images and logs
- `imgs/signature.tex` hand signature for Jochen Illerhaus
- `imgs/kit.tex` kit logao
- `imgs/irs.tex` irs logao
